# บันทึกการใช้รถ IT Department

ระบบบันทึกการใช้รถของแผนก IT (Dunkin' / Greyhound Cafe / Au Bon Pain / Funky Fries) หน้าเว็บอยู่บน GitHub Pages ส่วนข้อมูลเก็บใน MySQL ผ่าน API (FastAPI) ที่รันบนเซิร์ฟเวอร์ของบริษัท

| **API (Backend)** | https://vehiclelog.mobile1234.site — เช็กว่าทำงานอยู่ไหมที่ [`/health`](https://vehiclelog.mobile1234.site/health) |

## 🗂 ฐานข้อมูล (MySQL: `vehicle_log`)

**trips** — 1 แถว = 1 ทริป
`id, out_date, user_out, brand, dest_code, dest_name, purpose_type, purpose_detail, in_date, user_in, plate, mileage_start, mileage_end, status, photo_start, photo_end, gps_start, gps_end, created_at, updated_at`
- `status` = `in_progress` (ทริปสดที่ยังไม่จบ) หรือ `completed`
- `dest_*` / `purpose_*` ของทริป = ปลายทางสุดท้าย

**trip_stops** — จุดแวะระหว่างทางของทริปสด
`id, trip_id, seq, brand, dest_code, dest_name, purpose_type, purpose_detail, mileage, photo_path, gps, created_at`

**branches** — รายชื่อสาขา (เลขสาขาห้ามซ้ำในแบรนด์เดียวกัน)
`id, brand, shop_id, code, name`

**feedback** — ความคิดเห็น / แจ้งปรับปรุงระบบ
`id, kind, page, area, detail, images, author, status, reply, created_at, updated_at`
- `kind` = `add` (เพิ่มใหม่) / `fix` (แก้ไข) / `remove` (ลบออก) / `improve` (ปรับปรุง) · `status` = `open` / `doing` / `done`
- `images` = JSON array ของ path รูปใน `uploads/` (รูปที่วง/มาร์กแล้ว รวมเป็นรูปเดียวมาจากเว็บ)

**trip_photos** — รูปประกอบทริป (แนบจากฟอร์มกรอกย้อนหลัง / แก้ไขทริป) ทริปละไม่เกิน 6 รูป ลบทริปแล้วรูปถูกลบตาม (ON DELETE CASCADE)
`id, trip_id, seq, path, created_at`

ตาราง `feedback` และ `trip_photos` สร้างด้วย `/opt/vehiclelog/migration_feedback.sql` — user ของ API (`vehicle_log_api`) **ไม่มีสิทธิ์ CREATE** จึงต้องรันเองครั้งเดียว (รันซ้ำได้ ไม่เสียหาย):
```
sudo mysql vehicle_log < /opt/vehiclelog/migration_feedback.sql
```

## 🔌 API

| Method | Path | ใช้ทำอะไร |
|---|---|---|
| GET | `/trips` | ทริปทั้งหมด |
| POST | `/trips` | เพิ่มทริป (กรอกย้อนหลัง) · `Photos` = list path รูปจาก `POST /uploads` (ไม่ส่ง = ไม่มีรูป) |
| PUT / DELETE | `/trips/{id}` | แก้ไข / ลบทริป (ลบจุดแวะ+รูปของทริปนั้นไปด้วย) · PUT ส่ง `Photos` = แทนที่รูปทั้งชุด, ไม่ส่ง = ไม่แตะรูปเดิม |
| GET | `/trips/{id}/detail` | ทริป + จุดแวะทั้งหมด + `photos` (รูปประกอบ) |
| GET | `/trips/active` | ทริปสดที่ยังไม่จบ |
| POST | `/trips/start` | เริ่มทริปสด |
| GET / POST | `/trips/{id}/stops` | ดู / เพิ่มจุดแวะ |
| PUT / DELETE | `/stops/{id}` | แก้ไข (ปลายทาง / วัตถุประสงค์ / เลขไมค์) / ลบจุดแวะ — ทริปที่ยังไม่จบจะปรับไมค์ล่าสุดตามจุดแวะสุดท้ายให้เอง |
| POST | `/trips/{id}/finish` | จบทริป |
| POST | `/uploads` | อัปโหลดรูป (base64 ไม่เกิน 8 MB) ได้ URL กลับมา |
| GET / POST | `/branches` | ดู / เพิ่มสาขา |
| PUT / DELETE | `/branches/{id}` | แก้ไข / ลบสาขา |
| POST | `/branches/bulk` | เพิ่มสาขาหลายรายการ (แถวที่ซ้ำจะข้ามไป) |
| GET / POST | `/feedback` | ดู / ส่งความคิดเห็น (`Images` ต้องเป็น path ที่ได้จาก `POST /uploads` เท่านั้น) |
| PUT | `/feedback/{id}` | แก้ไขเนื้อหาทั้งเรื่อง (ประเภท / หน้า / จุด / รายละเอียด / รูป / ผู้แจ้ง) สถานะกับคำตอบกลับคงเดิม |
| PATCH / DELETE | `/feedback/{id}` | เปลี่ยนสถานะ / บันทึกตอบกลับ (`Status`, `Reply`) / ลบ |
| GET | `/health` | เช็กว่า API ทำงานอยู่ |

ถ้าสำเร็จจะตอบ `{"ok": true, ...}` ถ้าผิดพลาดจะได้ HTTP status 4xx/5xx พร้อมข้อความ error ใน `detail` (หรือ `error` ถ้าเป็น error ที่ backend ไม่ได้ดักไว้)

## ⚙️ วิธีอัปเดต

### หน้าเว็บ (ไฟล์ใน repo นี้)
1. แก้ไฟล์ แล้ว commit + push ขึ้น `main`
2. GitHub Pages อัปเดตเองภายใน 1–2 นาที ถ้ายังเห็นของเก่า ให้ปิดแท็บแล้วเปิดใหม่ (หรือกดรีเฟรชในแอป LINE)
3. อยากลองก่อนขึ้นจริง: เปิดไฟล์ในเครื่องโดยแก้ `CONFIG.API_URL` เป็น `''` หน้าเว็บจะเข้า **โหมดตัวอย่าง** ใช้ข้อมูลสาขาที่ฝังไว้ในไฟล์ ไม่ยุ่งกับข้อมูลจริง (**เปลี่ยนกลับก่อน push**)

### Backend (บนเซิร์ฟเวอร์)
1. แก้ `/opt/vehiclelog/main.py`
2. `sudo systemctl restart vehiclelog-api`
3. เปิด https://vehiclelog.mobile1234.site/health ต้องเห็น `{"ok":true,"service":"vehicle-log-api"}`
4. ถ้าไม่ขึ้น ดู log ด้วย `journalctl -u vehiclelog-api -n 100`

## 🖥️ วิธีใช้งานแต่ละหน้า

### 1. บันทึกการใช้รถ (`vehicle-log-v3.html`)
กดปุ่ม **+** มุมขวาล่าง เลือกได้ 2 แบบ
- **เริ่มทริปสด (ถ่ายรูปจริง)** — ใส่ชื่อ เลือกรถ ใส่เลขไมค์ ถ่ายรูป (ระบบเก็บพิกัด GPS ให้) → ระหว่างทางกด **เพิ่มจุดแวะ** ได้เรื่อยๆ → ถึงที่สุดท้ายกด **จบทริป** แล้วใส่ชื่อผู้คืนรถ
  ทริปที่ยังไม่จบจะโชว์เป็นการ์ดด้านบนของหน้า
- **กรอกข้อมูลย้อนหลัง** — กรอกทริปที่จบไปแล้วในฟอร์มเดียว แนบ **รูปภาพประกอบ** ได้สูงสุด 6 รูป: กด **ถ่ายรูป** (กล้องในเว็บ) หรือ **เลือกรูป / ไฟล์** (มือถือให้เลือกได้ทั้งกล้อง คลังรูป ไฟล์ Google Drive) — เว็บย่อรูปเหลือด้านยาวไม่เกิน 1600px ก่อนอัปโหลด แก้ไขทริปภายหลังก็เพิ่ม/ลบรูปได้ รูปโชว์ในหน้ารายละเอียดทริป

**การเลือกปลายทาง:** **แตะช่องสาขา จะเด้งหน้าค้นหาสาขาขึ้นมา** พิมพ์ค้นได้ทันทีด้วยเลขสาขา / ชื่อย่อ / ชื่อเต็ม (พิมพ์หลายคำได้ เช่น `lotus kon`) หรือเลื่อนหาแล้วแตะเลือกก็ได้ เปลี่ยนแบรนด์ในหน้าค้นหาได้เลย เลือกแล้วจะกลับมาที่ฟอร์มพร้อมใส่สาขาให้
- ค้นไม่เจอในแบรนด์ที่เลือก ระบบจะบอกว่าเจอในแบรนด์ไหนแทน แตะไปดูได้
- ที่ไปไม่มีในรายการ กด **ใช้ "…" เป็นชื่อปลายทาง** ได้
- ปุ่ม × ในช่องสาขาใช้ล้างค่า ส่วนปุ่มย้อนกลับของมือถือจะปิดแค่หน้าค้นหา ไม่หลุดออกจากฟอร์ม

อื่นๆ
- เลขไมค์เริ่มต้นดึงจากไมค์สิ้นสุดของทริปล่าสุดของรถคันนั้นให้อัตโนมัติ (แก้เองได้)
- สลับดูเป็น **รายการ** หรือ **ปฏิทิน** กรองตามรถแต่ละคันได้ กดที่ทริปเพื่อดูรายละเอียด รูป และเส้นทางจุดแวะ
- **เพิ่ม / แก้ไข / ลบ ครบทุกส่วน**:

  | ข้อมูล | เพิ่ม | แก้ไข | ลบ |
  |---|---|---|---|
  | ทริป | ปุ่ม + (ทริปสด / กรอกย้อนหลัง) | หน้ารายละเอียด → **แก้ไข** | ถังขยะในตาราง หรือหน้ารายละเอียด → **ลบทริป** (ลบทริปที่ยังไม่จบได้ด้วย) |
  | จุดแวะ | การ์ดทริปสด → **จุดแวะ** | หน้ารายละเอียด → **แก้ไข** ที่จุดแวะ (ไม่ต้องถ่ายรูปใหม่) | หน้ารายละเอียด → **ลบ** ที่จุดแวะ |
  | สาขา | หน้าจัดการข้อมูลสาขา | หน้าจัดการข้อมูลสาขา | หน้าจัดการข้อมูลสาขา |
  | ความคิดเห็น | ปุ่มมุมขวาบน → แจ้ง | เปิดเรื่อง → **แก้ไขเรื่องนี้** / เปลี่ยนสถานะ / ตอบกลับ | เปิดเรื่อง → **ลบเรื่องนี้** |
- ลิงก์ตรง: `vehicle-log-v3.html?trip=<id>` เปิดรายละเอียดทริป · `?trip=<id>&edit=1` เปิดฟอร์มแก้ไขทริปเลย
- กดไอคอน 📤 เพื่อ **Export CSV** เลือกช่วงวันที่ ไฟล์ที่ได้มี วันที่ออก-กลับ / ปลายทาง / ระยะทาง (กม.)

### 2. สรุปการใช้รถรายปี (`vehicle-report.html`)
เข้าจากการ์ดในหน้าแรก หรือลิงก์ **สรุปการใช้รถรายปี** ใต้หัวข้อหน้าบันทึกการใช้รถ เลือกปีด้วยลูกศร และกรองเฉพาะรถคันเดียวได้
- **ระยะทางรวมทั้งปี** + เฉลี่ยต่อวัน (วันปฏิทิน / เฉพาะวันที่ออกรถ) เฉลี่ยต่อเดือน เฉลี่ยต่อเที่ยว และสัดส่วนทริปที่มีเลขไมค์ครบ
- **ปีนี้ใช้รถกี่คัน ทะเบียนอะไร** แต่ละคันกี่เที่ยว กี่ กม. ใช้ครั้งแรก/ล่าสุดเมื่อไหร่
- **มากสุด / น้อยสุด**: เดือน, วัน, ทริปที่ไกลที่สุด/ใกล้ที่สุด, เดือนที่ไม่ได้ใช้รถ
- กราฟระยะทางรายเดือน (แยกสีตามรถ) + ตารางรายเดือน + ตารางเทียบทุกปี
- **ตรวจสอบความถูกต้องของข้อมูล**: ไม่มีเลขไมค์, ไมค์ติดลบ, ไมค์ย้อนกลับเทียบทริปก่อนหน้า, ไมค์ขาดช่วง (> 50 กม.), ทริปเดียวเกิน 1,000 กม., วันที่กลับก่อนวันออก, ทริปค้างไม่กดจบ, ไม่ระบุทะเบียน, บันทึกซ้ำ — แต่ละรายการมีปุ่ม **แก้ไขทริป** (เปิดฟอร์มแก้ไขทันที) และ **ดูรายละเอียด / ลบ**
- วิธีคำนวณทั้งหมดอยู่ท้ายหน้า (“วิธีคำนวณตัวเลขในหน้านี้”) · ค่าเกณฑ์ปรับได้ที่ `LONG_TRIP_KM`, `GAP_KM` ในไฟล์

### 3. จัดการข้อมูลสาขา (`branches-manager.html`)
- ค้นหา เพิ่ม แก้ไข ลบ สาขาได้โดยตรง กรองตามแบรนด์ได้
- กันเลขสาขาซ้ำในแบรนด์เดียวกันให้อัตโนมัติ

### 4. ความคิดเห็น / แจ้งปรับปรุงระบบ (ปุ่มรูปข้อความ มุมขวาบนของทุกหน้า)
- ตัวเลขบนปุ่ม = จำนวนเรื่องที่ยังไม่เสร็จ · กดแล้วเห็นทุกเรื่อง กรองตามสถานะ หรือเฉพาะหน้าที่เปิดอยู่ได้
- **แจ้งเรื่องใหม่**: เลือก เพิ่มใหม่ / แก้ไข / ลบออก / ปรับปรุง → เลือกหน้าและจุดของระบบ (หรือพิมพ์เอง) → เขียนรายละเอียด → แนบรูป
- **แก้ไขเรื่องที่ส่งไปแล้ว**: เปิดเรื่อง → แก้ไขเรื่องนี้ (เปลี่ยนได้ทุกช่อง เพิ่ม/ลบรูป มาร์กเพิ่มบนรูปเดิมได้) · **ลบ**: เปิดเรื่อง → ลบเรื่องนี้
- **แนบรูปจากเครื่อง** หรือ **จับภาพหน้านี้** (ถ่ายภาพหน้าเว็บที่เปิดอยู่ให้เลย) แล้ว **วงกลม / กรอบ / ลูกศร / ขีดเขียน / ใส่ข้อความ** ตรงจุดที่ต้องการ เลือกสีได้ ย้อนกลับได้ แตะรูปเพื่อแก้มาร์กก่อนส่งได้
- กดเข้าเรื่องเพื่อเปลี่ยนสถานะ (รอดำเนินการ → กำลังทำ → เสร็จแล้ว) และเขียนบันทึกการดำเนินการ / ตอบกลับ
- ปิดหน้าความคิดเห็นกลางคันได้ ร่างที่ยังไม่ส่งจะยังอยู่จนกว่าจะปิดแท็บ
